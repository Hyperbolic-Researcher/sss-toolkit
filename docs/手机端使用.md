# 手机端怎么用

## 一句话原理

**下载必须跑在电脑上**（需要代理、硬盘、算力），手机只是**遥控器**。
所以真正的关系是：

```
手机（遥控器） ──局域网──> 电脑（干活） ──代理──> YouTube
                              ↓
                         E 盘存视频
```

手机看不到视频文件本身，除非你把文件同步到手机或网盘。

## 场景一：在家用（最简单，已配好）

### 电脑端（一次性）

双击桌面上的 **`SSS工具.bat`**。

会弹出一个黑窗口，显示：

```
========================================================
  手机访问（需与电脑连同一个 WiFi）
  http://192.168.0.107:8765/
========================================================
  把这个地址在手机浏览器打开，建议添加到主屏幕
```

**这个窗口不能关**，关了服务就停了。

### 手机端

1. 手机连**同一个 WiFi**（必须和电脑同一路由器）
2. 打开浏览器，输入窗口里那个地址，例如 `192.168.0.107:8765`
3. 页面和电脑上完全一样，点按钮就能开始任务
4. 建议：浏览器菜单 → **添加到主屏幕**，以后像 App 一样点开

### 常见问题

**打不开怎么办**

| 症状 | 原因 | 解决 |
|---|---|---|
| 一直转圈 | 手机和电脑不在同一 WiFi | 检查 WiFi 名字是否一致 |
| 提示拒绝连接 | 黑窗口被关了 | 重新双击 `SSS工具.bat` |
| 提示拒绝连接 | Windows 防火墙拦了 | 首次运行时点"允许访问" |
| 地址对但打不开 | IP 变了（路由器重新分配） | 看黑窗口里最新打印的地址 |

**IP 每次都会变吗**

不一定，但可能会。每次启动都看黑窗口里打印的那个，以它为准。

想让 IP 固定：路由器后台把电脑的 MAC 地址绑定固定 IP（DHCP 静态分配）。

## 场景二：不在家也想用（进阶）

电脑必须开机，但可以通过内网穿透从外网访问。三种方案，按难度排序：

### 方案 A：Tailscale（推荐，最省事）

1. 电脑和手机都装 [Tailscale](https://tailscale.com/download)，用同一账号登录
2. 电脑上启动 `SSS工具.bat`
3. 手机打开 Tailscale，会看到一个 `100.x.x.x` 的地址
4. 手机浏览器访问 `http://100.x.x.x:8765`

优点：不用改路由器、自动加密、免费额度够个人用。
缺点：要装客户端。

### 方案 B：Cloudflare Tunnel

在电脑上执行：

```bash
winget install Cloudflare.cloudflared
cloudflared tunnel --url http://localhost:8765
```

会给你一个 `https://xxx.trycloudflare.com` 的临时地址，手机直接打开。

优点：不用装客户端，就是网页链接。
缺点：每次重启地址会变（除非配置固定域名）。

### 方案 C：路由器端口映射

在路由器后台把 8765 端口映射到电脑。

**不建议**：直接暴露到公网，没有密码保护，任何人都能点你的下载按钮。

如果非要用，先设环境变量加口令：

```bash
set SSS_TOKEN=你的口令
python webui.py --lan
```

然后访问时带参数：`http://你的地址:8765/?k=你的口令`

## 场景三：想在手机上看视频

工具本身不提供视频播放。你需要的其实是把文件弄到手机上，两条路：

**A. 电脑开共享，手机用播放器连**

电脑上右键 `E:\SuperSimpleSongs` → 属性 → 共享 → 高级共享 → 勾选"共享此文件夹"。
手机装 **VLC** 或 **nPlayer**，选"网络"→ SMB，输入电脑 IP 和账号密码。

**B. 同步到网盘**

用百度网盘 / 阿里云盘 / OneDrive 同步文件夹，手机装对应 App 直接看。

## 关于"更方便"这件事的边界

有三件事做不到，得说清楚：

1. **手机单独跑不了下载** — yt-dlp 需要 Python 环境 + 代理 + 大容量存储，手机不具备
2. **电脑关机就用不了** — 局域网和穿透都依赖电脑在线
3. **真正的"随时随地"要花钱** — 云服务器下载再传到手机，涉及服务器费、流量费、代理费，成本远高于自己电脑跑

如果哪天你确实需要完全脱离电脑，那时候再考虑云端方案，我可以帮你算成本。
