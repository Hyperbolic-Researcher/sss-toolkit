# 支持哪些网站

底层用 yt-dlp，内置 **1752 个站点解析器**。下面列的是主流站点，实测确认可用。

---

### 视频平台

| 站点 | 说明 |
|---|---|
| **YouTube** | ✅ 主力支持，含频道批量、播放列表、字幕、4K/8K |
| **Bilibili（B站）** | ✅ 支持；未登录只有 288p，高清需 `SESSDATA` cookie |
| **抖音** | ✅ 单个视频；不支持主页批量 |
| **小红书** | ✅ 单个笔记 |

| Vimeo | ✅ |
| Dailymotion | ✅ |
| TikTok | ✅ |
| Instagram | ✅（部分需登录） |
| Twitter / X | ✅ |
| Facebook | ✅ |
| Reddit | ✅ |
| Pinterest | ✅ |
| Tumblr | ✅ |

## 二、不支持（试了也没用）

| 站点 | 原因 |
|---|---|
| **微信视频号** | 微信生态封闭，无公开接口，技术上无解 |
| **快手** | yt-dlp 没有对应解析器 |
| 大部分国内网盘 / 私有平台 | 需要登录态或 DRM |

---

## 三、怎么自己判断支不支持

不需要查文档，一条命令：

```bash
python -m yt_dlp --simulate "你要下载的网址"
```

- 能打印出标题/格式 → **支持**
- 报 `Unsupported URL` → **不支持**

或者在本工具的网页里，把链接粘到「单视频下载」框里——解析得出来就是支持。

---

## 四、几点说明

**1. 支持 ≠ 能拿到高清**

YouTube 老视频的高清转码可能已被清理；B站未登录只有 288p。
「能下载」和「能下到最高画质」是两件事。

**2. 支持 ≠ 合法**

本工具只是技术手段。下载内容仍受版权保护，请勿用于商业分发，
并遵守目标网站的服务条款。

**3. 站点支持是动态的**

yt-dlp 每周更新解析器。某个站今天不支持，下周可能就支持了：

```bash
pip install -U yt-dlp
```

**4. 需要登录的站点**

部分站点（B站高清、Instagram、Facebook 私密内容）需要 cookie。
本工具目前没做 cookie 管理界面，需要手动放到 `cookies.txt`。
